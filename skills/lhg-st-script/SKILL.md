# lhg-st-script：谈判话术设计方法论

> 目标：把策略翻译成"嘴里说出来的话"。
> 核心纪律：**每句话都有目的（锚定/探询/交换/确认）；禁忌话术清单逐条排查，一句不留。**

## 1. 何时使用

- 策略已定（有 BATNA/三点定位/让步阶梯）→ 为每一轮设计话术
- 收到 HR 薪资电话/约面谈 → 针对性准备应对话术
- 演练前 → 先写话术稿，再进 lhg-st-drill 演练

## 2. 输入与输出

**输入**：`谈判准备.md`（策略）+ 本轮谈判场景（首轮开价 / 僵持 / 收尾）。

**输出**：`话术稿.md`——四阶段话术 + 异议应对话术库。

## 3. 分步方法论

### 3.1 第一阶段：开价（锚定）

公式：**依据 + 数字 + 价值**，三句缺一不可。

> "根据我调研的市场数据（依据），同类岗位中位数在 33-38k 之间。结合我过去三年主导的三个千万级项目（价值），我期望薪资是 38k（数字）。"

要点：
- 数字只说总包口径或月薪口径，全程统一，不许一会儿月薪一会儿年薪
- 依据要具体（"脉脉上同类岗位""两位同行交流"），不说"据我了解"这种空话
- 说完数字就停，不要自己先解释"是不是高了"——解释等于自我砍价

### 3.2 第二阶段：探询（摸对方的牌）

对方还价后，先探询再让步：

- "您看这个数字和贵司的预算差距大概在什么范围？"（摸预算）
- "除了 base，贵司的薪资结构里还有哪些部分可以谈？"（开筹码口子）
- "这个岗位的定薪主要参考哪些因素？"（摸决策逻辑）

**探询期不让步**。对方每压一次价，你回一个问题。让步是第三阶段的事。

### 3.3 第三阶段：让步（交换）

公式：**让步 + 对价**，每次让步都配一个交换条件。

> "如果预算确实有压力，我可以让步到 36k。作为交换，希望签约奖金能补足这部分差额。"

要点：
- 让步幅度递减（8% → 5% → 2%），让对方感到"越让越难"
- 让步间隔拉长，不要对方一开口你就松口
- 每次让步都强调"这是我能做的最大让步了"——哪怕不是，气势上也要是
- 让步到接近底线时，话术转为："这个条件我需要认真考虑一下，我们下周再约时间？"（以退为进，不断线）

### 3.4 第四阶段：收尾（书面确认）

谈定后 24 小时内必须落到纸面：

> "感谢，我们把今天谈定的条件形成书面 offer，以邮件确认后再推进后续流程。"

- 口头 offer 不作数：变卦零成本，维权零证据
- 书面 offer 逐项核对：base、年终、签约奖金、股票、职级、入职时间——谈过的每一条都要在纸上
- 发现口头与书面不一致 → 立刻指出，不要"先入职再说"

### 3.5 异议应对话术库

| 异议 | 应对话术思路 |
|---|---|
| "你期望超预算了" | "差距大概多少？如果 base 动不了，我们看看签约奖金和职级有没有空间"（转战场） |
| "你年限不够" | "年限是参考，我主导的 X 项目直接对标贵司 Y 业务，产出是……"（转价值） |
| "我们一向是这个价" | "理解贵司体系。那我了解一下，这个职级的上限是多少？达到上限需要什么条件？"（摸天花板） |
| "先降期望我们再谈" | "我们先对齐岗位价值，再谈数字。您看我刚才讲的项目经验，匹配度如何？"（拒绝先降） |
| "回去申请一下" | "好的，您预计什么时候有反馈？我这边也有流程在走，我们约个时间点对齐"（设 deadline） |

### 3.6 禁忌话术黑名单（出现一句，整稿打回）

1. **过早暴露底线**："我最低接受…""我的底线是…"（TALK-001）
2. **威胁式语言**："不给就走""我有的是 offer""爱要不要"（TALK-002）
3. **情绪化表述**："太不公平了""我很委屈""被压榨"（TALK-006）
4. **自我砍价**："是不是有点高？""我可以再低一点"（没人压价自己先降）
5. **贬低现公司**："我现在公司太差了"（等于告诉对方你非走不可）
6. **撒谎**：虚报在手 offer 的数字（背调一问就穿，诚信破产）

### 3.7 电话谈判 vs 面谈的差异打法

| 维度 | 电话 | 面谈 |
|---|---|---|
| 优势 | 有纸笔记录、可看提纲、情绪不外露 | 能读表情、可递材料、仪式感强 |
| 劣势 | 对方也可能在演、难读空气 | 紧张时表情出卖你、不能看稿 |
| 打法 | 语速放慢 20%，关键数字重复确认（"您刚说的是 35k 对吗，我记一下"） | 带一页纸提纲（不是稿），眼神交流，沉默时微笑不补话 |

**共同点**：都不许当场拍板。电话里说"我考虑一下"，面谈时说"我回去和家人商量一下"——理由不重要，留白才重要。

### 3.8 首轮开价逐字稿示例（可直接改数字套用）

> "感谢贵司的认可。关于薪资，我先同步一下我的调研（依据）：脉脉上同类岗位的中位数在 33-38k 之间，我交流过的两位同行，base 也都在这个区间（具体化依据）。结合我过去三年主导的三个项目——其中 X 项目直接对标贵司 Y 业务，上线后转化率提升 12%（价值），我期望薪资是 38k（数字）。"
>
> （停顿，等对方反应。对方还价后：）
>
> "理解，预算确实要综合考虑。您看差距大概在什么范围？除了 base，贵司的薪资结构里签约奖金和职级这两块有没有空间？（探询，转战场）"

**注意**：逐字稿是示例不是圣经。把括号里的依据、价值、数字换成你自己的，语气换成你自己的——背下来的稿子一听就是假的。

### 3.9 沉默的艺术

谈判中最被低估的武器是沉默。说完开价后，闭嘴，等对方先开口。先开口补话的人，大概率是让步的人。

- 开价后沉默：让对方消化数字，消化不了他会自己找台阶（"这个确实有点超预算…"——好，探询开始）
- 对方压价后沉默 5 秒：再回探询问题。秒回等于告诉对方"你急了"
- 僵持时沉默：微笑，不补话。谁先补话谁让步

**练习方法**：演练时教练在你说完关键句后故意沉默 8 秒，记录你忍了几秒。目标：8 秒一句话不说，还能微笑。

## 4. 反模式

- ❌ 话术稿写成"演讲稿"——谈判是轮次制的，一轮只讲一个点，写成长篇大论等于一次暴露所有底牌
- ❌ 只准备"说什么"，不准备"问什么"——探询问题和话术同等重要
- ❌ 背稿——话术是提纲不是台词，背下来的一听就是假的；记要点，现场组织语言
- ❌ 情绪上头——被压价时深呼吸，记住：对方压价是工作，不是针对你
- ❌ 当场拍板——永远留"我考虑一下"，给自己留复盘和比价的时间

## 5. 自检与反馈

话术稿写完逐项打勾：

1. 四阶段是否齐全（开价/探询/让步/收尾）？→ 缺收尾的书面确认直接打回
2. 每个数字后面都有依据吗？→ 裸奔的数字全部补依据
3. 每次让步都配了对价吗？→ 单方面让步全部改写
4. 禁忌黑名单 6 条逐条排查了吗？→ 中一条整稿打回
5. 异议库是否覆盖对方最可能说的 3 句话？→ 没覆盖就补
6. 跑一遍 `script_audit.py`，blocker 是否清零？→ 没跑不算做

标准冒烟用例：对插件自带的 `fixtures/` 跑脚本，确认坏 fixture 的 blocker 全命中、好 fixture 零 blocker（见仓库根 `smoke_test.py`）。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-salary-talk/issues，正文写清"输入 → 错误输出 → 期望输出"。
