# lhg-st-strategy：薪酬谈判策略方法论

> 目标：上桌前把"怎么谈"想清楚，而不是临场发挥。
> 核心纪律：**BATNA、底线、让步阶梯三件套必须书面化；市场薪资数据必须来自用户亲手核实的来源，绝不编造。**

## 1. 何时使用

- 拿到 offer / 进入薪资谈判环节 → 跑全流程
- 只有口头意向、还没谈钱 → 先做第 3.1~3.2 节，谈判时再补全
- 跳槽季做准备 → 用第 3 节搭好模板，多家公司复用

## 2. 输入与输出

**输入**：
- 岗位信息（公司/岗位/职级/工作地点）
- 用户亲手核实的市场薪资数据（带来源，如招聘软件截图、猎头报价、同行交流）
- 用户的 BATNA（在手 offer / 在流程中的机会 / 留任选项）

**输出**：`谈判准备.md`——BATNA、三点定位、让步阶梯、备选筹码、异议应对、风险预案。

## 3. 分步方法论

### 3.1 信息收集（谈判力的 70% 在桌下）

先回答五个问题，答不上来不许上桌：

1. **对方的薪资结构**：base 占比多少？年终几个月？有没有签约奖金/股票？（结构不同，谈法不同）
2. **职级对应的薪资带宽**：这个职级上下限是多少？（猎头、脉脉、看准网多方交叉）
3. **对方的紧迫度**：岗位空了多久？是不是急招？（越急，你的议价越高）
4. **你的稀缺性**：你的技能在市场上好不好找？有没有对口项目经验？
5. **决策链**：和你谈的人（HR）有没有拍板权？最终是谁批？（HR 常说"我去申请一下"——那是流程，不是拒绝）

### 3.2 BATNA：先想退路，再想进路

BATNA（最佳备选方案）是谈判的底气来源。书面写清：

- 在手 offer：公司/总包/到手时间
- 在流程中的机会：到哪一轮、预计出结果时间
- 留任选项：现公司能否加薪/晋升

**BATNA 使用原则**：让对方"知道"你有备选，但不说细节。"我手上有两个在走的流程"就够了，报具体公司名等于把底牌亮给对方去背调。BATNA 越强，开价可以越高；BATNA 弱，就把重点放在"价值论证"而非"价格强硬"上。

### 3.3 三点定位：开价 / 目标 / 底线

| 点位 | 定义 | 怎么定 |
|---|---|---|
| 开价 | 首轮报出的数字 | 市场数据上沿 + 你的稀缺性溢价，留出让步空间 |
| 目标 | 真正想拿到的数字 | 市场中位数偏上，谈判努力可达 |
| 底线 | 低于此就走人（walk-away） | 算出来的"最低可接受总包"，不是拍脑袋的 |

**铁律**：底线只写在准备文档里，永远不要说出口（话术审计 TALK-001 会抓）。开价要有依据：每个数字后面跟一句"根据……数据"。

### 3.4 让步阶梯：提前写好，临场不乱

设计至少 3 轮让步，每轮写清"让多少、换什么"：

- 第一轮：开价 → 让 5%~8%，交换签约奖金/入职时间等小条件（试探对方弹性）
- 第二轮：再让 3%~5%，交换职级/股票等实质条件（进入深水区）
- 第三轮：接近底线，只做象征性让步，交换远程办公/Title 等软性条件
- 底线：到线即停，话术转为"这个条件我需要再考虑一下"（留回旋，不当场撕破）

**让步节奏**：幅度递减（越让越小），间隔拉长。一次让到位等于告诉对方"还能再压"。

### 3.5 备选筹码：第二战场

base 谈不拢时，筹码清单就是 Plan B（按对你价值排序）：

1. 签约奖金（签字费）：一次性，最容易谈
2. 股票/期权：看公司阶段，上市公司折现实在
3. 职级：影响下一次跳槽的起点
4. 年假/远程办公：生活质量的硬通货
5. 入职时间/试用期：灵活性筹码

每个筹码标注"对方成本"与"你的收益"，谈判时专挑"对方成本低、你收益高"的先谈。

### 3.6 风险预案

- 对方说"超预算了"→ 问"预算上限是多少"，把皮球踢回去；同时启动备选筹码
- 对方拖延 → 设定自己的 deadline（与 BATNA 的 offer 截止日挂钩）
- 对方要求先降期望再谈 → 拒绝："我们先对齐岗位价值，再谈数字"
- 谈崩 → 按 BATNA 执行，不回头（回头等于告诉所有人你的底线是假的）

### 3.7 薪资结构拆解：谈判的会计学

谈判前把"总包"拆开算，不同公司的结构不可比：

| 结构项 | 谈判要点 |
|---|---|
| 月薪 base × 月数 | 核心，优先谈；注意 12/13/14/16 薪的口径差异 |
| 年终奖 | 问清"几个月"是保底还是绩效浮动，写进 offer 再信 |
| 签约奖金 | 一次性，最容易谈，常用来补 base 差距 |
| 股票/期权 | 问归属期（vesting）和行权价；未上市公司期权先打三折看 |
| 补贴（餐补/房补/交通） | 蚊子腿，但可以作为"对方让步"的台阶 |

**口径统一**：全程用"年总包"对比。对方说"月薪 30k，16 薪"，你算 48 万总包；别家"月薪 35k，13 薪"是 45.5 万——月薪高的总包未必高。

### 3.8 多 offer 并行的时间管理

1. 以最早出结果的 offer 为基准，倒排其他流程（"我这边下周三前要做决定，能否加快？"）
2. 不要拿 A 的 offer 去压 B 的 HR 太多次——用一次是筹码，用三次是人品问题
3. 每个 offer 的 deadline 写进 BATNA 时间线，谈判 deadline 与之挂钩才可信

### 3.9 谈判的时间窗口

- **最佳窗口**：对方发出口头 offer 后的 3~7 天。太早（还没意向）没筹码，太晚（HC 快关）被动。
- **不要在周五下午谈**：对方想下班，你想拿结果，双方都草率。约周二到周四上午。
- **deadline 是武器**：你的 deadline 必须真实（与 BATNA 的 offer 截止日挂钩），编造的 deadline 一戳就穿。

## 4. 反模式

- ❌ 编造市场薪资数据——本插件的红线。数据必须用户亲手核实并写清来源，无来源的数字按 PREP-007 标 warning
- ❌ 没有 BATNA 就上桌——等于裸奔，对方一眼看穿
- ❌ 底线说出口——说出口的底线就变成了新的开价起点
- ❌ 让步无交换——单方面降价只会引来下一轮压价
- ❌ 把"想要"当"应得"讲——谈判桌上只认价值与依据，不认委屈
- ❌ 当场拍板——永远留一句"我需要考虑一下"，给自己留复盘时间

## 5. 自检与反馈

跑完本 skill，对着清单打勾：

1. 五个信息问题都有答案吗？→ 有"大概"没"确切"不算
2. BATNA 是否书面化且有时间线？→ 口头说有不算
3. 三点定位三个数字都算出来了吗？→ 只有开价没有底线不算
4. 让步阶梯是否每轮都有"让多少、换什么"？→ 只有幅度没有交换不算
5. 市场数据是否每个数字都标注了来源？→ 没来源的数字全部删掉或补来源
6. 风险预案是否覆盖"超预算/拖延/谈崩"三种情况？→ 缺一种补一种

标准冒烟用例：对插件自带的 `fixtures/` 跑脚本，确认坏 fixture 的 blocker 全命中、好 fixture 零 blocker（见仓库根 `smoke_test.py`）。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-salary-talk/issues，正文写清"输入 → 错误输出 → 期望输出"。
