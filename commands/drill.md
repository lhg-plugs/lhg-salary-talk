# /lhg-salary-talk:drill —— 话术演练

用户输入在 `$ARGUMENTS` 中：`[--round 首轮|僵持|收尾]`。缺省覆盖全流程。

## 流程（加载 lhg-st-script 写稿 + lhg-st-drill 演练）

### 1. 写话术稿
按四阶段写 `话术稿.md`：
- 开价：依据 + 数字 + 价值（三句缺一不可）
- 探询：准备 3 个摸对方底牌的问题（预算/结构/决策逻辑）
- 让步：每轮"让多少、换什么"，幅度递减
- 收尾：书面 offer + 邮件确认（口头 offer 不作数）

### 2. 禁忌扫描
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/script_audit.py --target <目录> --format text
```
过早暴露底线、威胁式语言 → blocker，必须清零。情绪化表述、让步无交换 → warning，修掉或写豁免。

### 3. 角色扮演（2 轮）
- 助手扮"为公司省钱"的 HR，该压价就压价，不放水
- 第一轮顺境：走完流程，把话术说顺
- 第二轮逆境：强硬压价，练"不翻脸、不松口"
- 每轮 10~15 分钟，结束后立刻填复盘表（三问：哪次让步早了/哪个异议没接住/哪次该沉默说了话）

### 4. 极速模式
临时接到 HR 电话：用 lhg-st-drill 第 3.4 节 15 分钟极速演练（默念三点定位→预想 3 个异议→纸笔记录）。

## 硬规则
- 演练时不许看稿念——上桌没稿可看
- 教练放水 → 演练作废，这是自我安慰不是准备
- 练完不填复盘表 → 等于没练
