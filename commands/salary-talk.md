# /lhg-salary-talk:salary-talk —— 薪酬谈判一条龙

用户输入在 `$ARGUMENTS` 中：`[公司/岗位] [--round 首轮|僵持|收尾]`。岗位缺省则先问用户。

## 流程（全程按四个 skill 推进）

### 第 1 步：信息输入（加载 lhg-st-strategy）
向用户要四样东西，缺一不可：
1. 岗位信息：公司/岗位/职级/地点
2. **用户亲手核实的市场薪资数据**（带来源）——**助手绝不编造薪资数字**，没有数据就先标"待用户补充"
3. 用户的 BATNA（在手 offer / 在流程中的机会 / 留任选项）
4. 对方的薪资结构（base/年终/股票，知道多少说多少）

### 第 2 步：谈判策略（加载 lhg-st-strategy）
输出 `谈判准备.md`：BATNA、三点定位（开价/目标/底线）、让步阶梯（3 轮，每轮"让多少、换什么"）、备选筹码、异议应对、风险预案。用户确认后再往下走。

### 第 3 步：话术演练（加载 lhg-st-script + lhg-st-drill）
1. 按四阶段写 `话术稿.md`：开价锚定 → 探询 → 让步交换 → 收尾书面确认
2. 跑 `script_audit.py` 扫禁忌话术（过早暴露底线/威胁式语言），blocker 清零
3. 角色扮演演练 2 轮（顺境 + 逆境），助手扮"为公司省钱"的 HR，每轮填复盘表

### 第 4 步：底线清单（加载 lhg-st-audit）
1. 跑 `prep_audit.py` + `script_audit.py`，blocker 清零
2. 人工复核：数字重算、话术试读、底线默写
3. 输出一页纸 `底线清单.md`（开价/目标/底线/阶梯/绝不说的三句话/deadline），结论"通过 / 不通过"

## 硬规则
- 编造薪资数字 → 整个交付作废，这是红线
- 底线只写在文档里，永远不要说出口
- 没有 BATNA 就上桌 → 必须先提醒用户风险，由用户决定是否继续
- 当场拍板 → 永远留"我考虑一下"
